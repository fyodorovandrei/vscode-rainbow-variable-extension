# Change Log

All notable changes to the "rainbow-variables" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [1.0.0] - 2026-06-05

Initial public release.

- Added AST-based rainbow coloring for JavaScript and TypeScript parameters and local variables.
- Added coloring of imported bindings and their usages in type annotations and extends clauses.
- Added extension settings for palette, font weight, supported languages, imports, parameters, variables, and file size limits.
- Added refresh and toggle commands.
- Added a status command to diagnose why an editor is skipped or how many identifiers were highlighted.
